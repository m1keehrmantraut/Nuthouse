# 06 — Враги, Мир, Сервисы, Меню, UI

## Enemy/ — враги
Папка `Assets/Scripts/Enemy/`.
- `EnemyHealth.cs` `[переход]` — наследник `DamageReceiver`: HP из SO, при уроне — кровь, при смерти — анимация, обездвиживание, fade и `Destroy`. Публикует `DamageEvents.Died`.
- `MeleeEnemy.cs` `[legacy/переход]` — простое «бьющееся» поведение: ищет игрока по тегу, в радиусе бьёт через `player.ApplyDamage` (по новому пути `DamageInfo` → `Health`). Поиск игрока по тегу — legacy, позже уйдёт.
- `EnemyMovement.cs` `[legacy]` — примитивное преследование игрока (`transform.MoveTowards`), флип масштабом, анимация скорости. Позже заменится AI-системой.

## World/Interact/ — мир
Папка `Assets/Scripts/World/Interact/`.
- `Interactable.cs` `[новый, абстрактный]` — базовый класс «с чем можно взаимодействовать»: радиус, флаг доступности, метод `Interact(PlayerFacade)`.
- `AxeInteractable.cs` `[новый]` — лежащий/застрявший топор: при взаимодействии возвращает игроку 1 топор (`player.ReturnAxe(1)`) и уничтожает снаряд.

## Services/ — сервисы приложения
Папка `Assets/Scripts/Services/`.
- `ISceneService.cs` / `SceneService.cs` `[новый]` — интерфейс + реализация: загрузка сцен, порядок сцен, переходы (меню/следующая).
- `IProgressService.cs` / `ProgressService.cs` `[новый]` — интерфейс + реализация: прогресс (PlayerPrefs), завершённые сцены, сброс.
Регистрируются `GameBootstrap`; геймплей их НЕ читает (только меню/UI/презентация).

## Menus/ — меню
Папка `Assets/Scripts/Menus/`.
- `PauseMenu.cs` `[переход]` — пауза. Подписан на `GameEvents.PauseRequested` (от `InputReader`/Escape) → ставит `Time.timeScale≈0`, разворачивает панель, меняет громкость.
- `MainMenu.cs` `[legacy]` — кнопки главного меню. Пока зовёт старый `GameProgress.Instance` (позже перейдёт на `ISceneService`/`IProgressService`).
- `SettingsMenu.cs` `[legacy]` — меню настроек.
- `GameProgress.cs` `[legacy]` — старый ручной Singleton: сцены + PlayerPrefs. Разбирается на `SceneService`/`ProgressService`; пока остаётся как есть.

## UI/ — интерфейс
Папка `Assets/Scripts/UI/`.
- `StaminaBar.cs` `[переход]` — полоса стамины. Читает нормированную стамину из `PlayerFacade.StaminaNormalized` (новая `Stamina`). Ссылку на игрока можно перетащить в поле `PlayerFacade`, иначе ищется по тегу `Player`.
- `StaminaBarFollow.cs` `[legacy, presentation]` — полоса стамины следует за объектом (world→screen).
- `UIFollowNPC.cs` `[legacy, presentation]` — UI-элемент следует за NPC/объектом.
- `DisplayText.cs` `[legacy, presentation]` — текстовый «глитч-принтер» (печать с глитч-символами, fade) для диалогов/всплывающего текста.
- `CustomDropdown.cs` `[legacy, presentation]` — класс `CustomResolutionDropdown`: выбор разрешения, пишется в PlayerPrefs.

## Active objects/ — старая папка мира (пробел в имени; позже → `Scripts/World`)
Папка `Assets/Scripts/Active objects/`.
- `InteractableObject.cs` `[legacy]` — старые интерактивные объекты (двери): по `E` рядом вызывают UnityEvent, показывают инфо/обводку. Своя система, НЕ связана с новым `InteractController` (тот для топора).
- `StairController.cs` `[legacy]` — включает/выключает коллайдеры лестниц (верх/низ).
- `QuickTrigger.cs` `[legacy]` — триггер перехода между сценами по касанию игрока.
- `CutsceneManager.cs` `[legacy/заглушка]` — заглушка катсцен: запускает `PlayableDirector`.
- `TextingObject.cs` `[legacy]` — всплывающий/диалоговый текст мира.
- `NPC/NPCDialogue.cs` `[legacy]` — диалог с NPC.
