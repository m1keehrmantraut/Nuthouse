# 07 — Не-кодовые ресурсы (кратко)

## Assets/Data/ — ScriptableObjects-конфиги
- `Movement/MovementConfig.asset` `[SO]` — числа движения (6/10 юнит/с, прыжок 16 …). Подбирались под маленького (~1–2 юнита) персонажа.
- `Input/InputConfig.asset` `[SO]` — окна буферизации кнопок.
- `Attacks/Attack1.asset` `[SO]` — ближняя атака (фазы 0.08/0.1/0.22, урон 50, хитбокс 3×1). NOTE: игрок сейчас ~14 юнитов — масштаб конфликтует, см. `08-…`.
- `Attacks/AxeThrow.asset` `[SO]` — бросок топора (фазы, урон 35, 2 топора). `axePrefab` пока ПУСТОЙ — см. `08-…`.
- `Characters/HealthConfig.asset` `[SO]`, `StaminaConfig.asset` `[SO]` — HP/инвулн/stagger и стамина.

## Assets/Input/
Должен быть ассет `PlayerInputActions.inputactions`. Сейчас `InputReader` создаёт карту программно (в коде), а не из ассета — рабочая заглушка, позже мигрирует на настоящий ассет.

## Assets/Prefabs/
- `SystemPrefabs/GameBootstrap.prefab` — точка старта/регистрация сервисов. NOTE: пока не добавлен в сцены.
- Префабы `Player.prefab` и `AxeProjectile.prefab` ОТСУТСТВУЮТ — игрок собран прямо в сцене; топор нужно создать (см. `08-…`).
- `Enemy.prefab`, двери/обстановка, системные префабы — на месте.

## Animation/
- `Player.controller` — аниматор игрока. Параметры по табл. `06-EventsAndPresentation §2` (`Speed`, `VerticalVelocity`, `Grounded`, `IsRunning`, `IsCrouching`, `Attack1/2/3`, `ThrowAxe`, `Hurt`, `IsDead`). Сверять с `PlayerAnimatorDriver`.

## Scenes/
- `MainMenu`, `HomeLocation`, `MainLocation`, `Stairs`/`Game` — игровые сцены с экземпляром игрока. В сценах `MainLocation`/`Game`/`Stairs`/`HomeLocation` игрок — объект с `PlayerFacade`; NOTE: поля `Hurtbox` пустые и компонент `PlayerAnimatorDriver` отсутствуют — см. `08-…`.
