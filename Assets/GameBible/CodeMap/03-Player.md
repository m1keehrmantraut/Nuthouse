# 03 — Player (игрок)

Папка `Assets/Scripts/Player/`. Самое большое и важное место: всё про игрока.

Игрок собирается на одном объекте. «Корень» — `PlayerFacade`. Подсистемы общаются через общий контейнер `PlayerContext`, а не напрямую друг с другом.

## Корень
- `PlayerContext.cs` `[новый]` — простой контейнер ссылок (без логики): мотор, ввод, буфер, здоровье, стейты и т.д. Также флаг `PendingHeavyAttack` (какая ближняя атака запускается). Создаётся в `PlayerFacade.Awake` и раздаётся всем подсистемам.
- `PlayerFacade.cs` `[новый]` — «дирижёр» и единственный MonoBehaviour игрока. В `Awake` создаёт все подсистемы, регистрирует стейты, привязывает Hurtbox, тикает всё в правильном порядке (`Update`/`FixedUpdate`). Держит SO ближних атак: лёгкая (`PrimaryAttack`) и тяжёлая (`HeavyAttack`, hold-charge). Внешний мир (диалоги, враги, UI) общается с игроком только через его публичные методы (`ReturnAxe`, `ApplyDamage`, `SetControlEnabled`, `StaminaNormalized`). Legacy-компоненты (старое движение, `MeleeCombat`, `PlayerHealth`) удалены.

## States/ — поведения игрока (стейт-машина)
Иерархическая FSM: есть родительские стейты (общая логика «на земле»/«в воздухе») и дочерние.
- `GroundedState.cs` `[новый, абстрактный]` — общее «на земле»: земли нет → `Fall`; умер → `Dead`; читает буфер на прыжок/атаку/бросок.
- `AirborneState.cs` `[новый, абстрактный]` — общее «в воздухе»: земля回来了 → `Idle`/`Crouch`; jump-cut (обрезка прыжка при отпускании кнопки).
- `IdleState.cs` `[новый]` — стоит. Есть ввод по горизонтали → `Run`; зажат Crouch → `Crouch`.
- `RunState.cs` `[новый]` — бежит. Тратит стамину, считает скорость (бег/ходьба). Ввода нет → `Idle`.
- `CrouchState.cs` `[новый]` — присел (медленно, ниже). Crouch отпущен и нет потолка → `Idle`.
- `JumpState.cs` `[новый]` — взлёт (vy>0). В `Enter` прыгает, потребляя coyote-окно. vy≤0 → `Fall`. Горизонталь — в `FixedTick`.
- `FallState.cs` `[новый]` — падение (vy≤0). Земля → `Idle`/`Crouch`. Горизонталь — в `FixedTick`.
- `AttackState.cs` `[новый]` — ближняя атака (лёгкая или тяжёлая — по флагу `PendingHeavyAttack`). Запускает `AttackRunner` по фазам (startup/active/recovery), может продолжить комбо в cancel-окне. `lockMovement` — не едет по инерции.
- `AxeThrowState.cs` `[новый]` — бросок топора. Фазы `Windup → бросок → Recovery → Done`. Один топор тратится строго в момент броска (нет потери при отмене на замахе).
- `HurtState.cs` `[новый]` — получил откидывающий урон: применяет нокбэк, ждёт stagger, затем в `Idle`/`Fall`.
- `DeadState.cs` `[новый]` — мёртв: гасит скорость, применяет гравитацию (труп не катится).

## Movement/ — физика
- `CharacterMotor.cs` `[новый]` — единственный, кто трогает `Rigidbody2D` игрока. Скорость, ускорение, прыжок, гравитация, импульсы, нокбэк. Использует Unity 6 `linearVelocity`.
- `GroundDetector.cs` `[новый]` — земля (`OverlapCircle` под ногами), coyote-таймер, потолок (чтобы не вставать из приседа под низким потолком).
- `FacingController.cs` `[новый]` — направление взгляда: flip через `localScale.x`. На время атаки запирается (`Lock/Unlock`).
- `MovementConfig.cs` `[новый, SO]` — все числа движения (скорости, ускорения, прыжок, гравитация, coyote).

## Combat/ — точка входа в атаки игрока
- `PlayerCombat.cs` `[новый]` — боезапас топоров (`AxesCount`), методы `TakeAxe`/`ReturnAxe`, спавн снаряда `SpawnAxe`. Хранит ссылки на SO атак.

## Interact/ — взаимодействие
- `InteractController.cs` `[новый]` — по нажатию `Interact` ищет ближайший `Interactable` в радиусе (`OverlapCircle` по слою) и зовёт его. Сейчас в основном для подбора топора.

## Presentation/ — анимация
- `PlayerAnimatorDriver.cs` `[новый]` — единственное место, где разрешён `Animator.*`. Подписан на смену стейта и события боя/урона, выставляет параметры аниматора (`Speed`, `Grounded`, триггеры атак и т.д.). NOTE: пока НЕ повешен на игрока в сценах — см. `08-Починка-в-редакторе.md`.

## Legacy — удалено
Раньше здесь лежали `CharacterController2D`, `PlayerMovement`, `PlayerHealth`, `MeleeCombat` и переходный `LegacyState`. Все удалены по GameBible: движение → `CharacterMotor`/стейты, бой → `AttackState`/`AttackRunner`/`Hitbox`, HP/стамина → `Health`/`Stamina`. В 4 игровых сценах на игроке остались их компоненты как «Missing Script» — снять руками (см. `08-Починка-в-редакторе.md`, шаг 0).
