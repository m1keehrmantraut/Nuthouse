# 04 — Combat (общее для боя)

Папка `Assets/Scripts/Combat/`. Классы урона, общие для игрока и врагов.

## Данные об уроне
- `DamageInfo.cs` `[новый, struct]` — пакет урона: количество, тип (`DamageType` — тоже здесь: Physical/Ranged), направление, сила нокбэка, источник (GameObject). Неизменяемая структура.
- `IDamageable.cs` `[новый, интерфейс]` — «по чему можно нанести урон»: `TakeDamage(in DamageInfo)`.
- `HurtRequest.cs` `[новый, struct]` — запрос на отбрасывание игрока (урон + направление + сила). `Health` кладёт его в контекст, фасад переводит в `HurtState`.

## Хитбоксы
- `Hitbox.cs` `[новый, MonoBehaviour]` — «чем бьют» (оружие/снаряд) на один удар: знает текущий `DamageInfo`, владельца и список уже битых целей. `TryHit` — дедупликация: одна цель получает урон один раз за фазу/полёт. Бонусом — fallback-триггер для старых врагов без `Hurtbox`.
- `Hurtbox.cs` `[новый, MonoBehaviour]` — «по чему бьют» (тело персонажа/врага). Враги: ссылка на `DamageReceiver` в инспекторе; игрок: `Bind(Health)` в фасаде. Игнорирует свой хитбокс (`IsOwnedBy`).

## Атаки (ближний бой)
- `AttackDefinition.cs` `[новый, SO]` — параметры атаки: фазы (`startup/active/recovery`), урон, нокбэк, размер/смещение хитбокса, выпад (`lunge`), блок движения, комбо-ссылка, триггер анимации. Лёгкая (`Attack1.asset`) и тяжёлая (`Attack2.asset`) — два отдельных ассета; какую запускать — решает `AttackState` по флагу `PendingHeavyAttack` (hold-charge из `InputReader`).
- `AttackRunner.cs` `[новый]` — исполняет фазы атаки: включает хитбокс строго на `Active`, выключает на `Recovery`, расставляет его по размеру/офсету (зеркалом рулит `Facing` через flip родителя), публикует `AttackStarted` и `AttackHit`. Дедупликация — через `Hitbox`.

## Снаряды
- `Projectiles/AxeProjectile.cs` `[новый, MonoBehaviour]` — летящий топор: физика, вращение (визуальное или физическое), хитбокс активен весь полёт. При попадании: во врага → урон + застревание; в мир → втыкание; иначе отскок. Затем на нём включается `AxeInteractable` для подбора.
- `AxeThrowDefinition.cs` `[новый, SO]` — параметры броска: фазы `windup/recovery`, сила, добавка вверх, скорость вращения, урон, поведение при контакте, префаб топора, стартовый боезапас. NOTE: `axePrefab` пока пустой — см. `08-Починка-в-редакторе.md`.
